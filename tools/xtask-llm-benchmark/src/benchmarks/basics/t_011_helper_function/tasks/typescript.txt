Write a SpacetimeDB backend module in TypeScript that defines a table, a non-reducer helper function, and a reducer that uses the helper.

TABLE
- result (public)
  - Fields:
    - id: number (i32, primary key)
    - sum: number (i32)

HELPER FUNCTION
- add(a: number, b: number): number - returns a + b

REDUCERS
- computeSum: given id:number (i32), a:number (i32), b:number (i32), insert row with sum=add(a,b)
