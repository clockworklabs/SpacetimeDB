Write a SpacetimeDB backend module in TypeScript that maintains a table of currently connected players using lifecycle reducers.

TABLE
- online_player (public)
  - Fields:
    - identity: identity (primary key)
    - connectedAt: timestamp

REDUCERS
- clientConnected: lifecycle reducer that inserts an online_player row with the caller's identity and the current time as connectedAt
- clientDisconnected: lifecycle reducer that deletes the online_player row for the caller's identity
