Write a SpacetimeDB backend module in C# that maintains a table of currently connected players using lifecycle reducers.

TABLE
- OnlinePlayer (public)
  - Fields:
    - Identity: Identity (primary key)
    - ConnectedAt: Timestamp

REDUCERS
- ClientConnected: lifecycle reducer that inserts an OnlinePlayer row with the caller's identity and the current time as ConnectedAt
- ClientDisconnected: lifecycle reducer that deletes the OnlinePlayer row for the caller's identity
