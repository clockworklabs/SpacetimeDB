Write a SpacetimeDB backend module in C# that exposes an upload route and an external upload procedure.

The caller supplies sample bytes and a public HTTP echo endpoint, such as https://postman-echo.com/post. Send only those supplied bytes, then store the response metadata.

TABLE
- UploadedAsset (public, accessor UploadedAsset)
  - Fields:
    - Id: ulong (primary key)
    - Url: string
    - Size: ulong
    - Status: ushort
    - ResponseBodyPresent: bool

HANDLER
- POST /upload
  - Return status 201
  - Return body "https://files.local/object-1"

PROCEDURE
- UploadAndRegister(uploadUrl: string, data: byte[]) -> string
  - POST the binary data to the supplied public URL
  - Require a successful response
  - Open a transaction and store Id 1, the supplied URL, the byte length, the response status, and whether the response body is non-empty
  - Return the supplied URL

ROUTER
- Register POST /upload through an HTTP router
