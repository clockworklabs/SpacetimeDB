Write a SpacetimeDB backend module in C# that tracks presence across multiple sessions. Return only the module source.

Track real connection lifecycle events. One identity may have multiple simultaneous connections. Disconnecting one connection must not mark its other connections offline. Reconnect must rebuild presence without leaving stale sessions. Do not add seed or exercise reducers. The grader opens actual WebSockets with shared and distinct credentials.

Tables (the first field is the primary key):
- public LiveSession: ConnectionId: ConnectionId, Owner: Identity
- public OnlineUser: Owner: Identity, Connections: ulong

When a client connects, insert a LiveSession using its connection ID and identity, and increment that identity's OnlineUser count (insert at 1). When a client disconnects, remove exactly that connection if it exists, decrement its owner's count, and delete OnlineUser only when the count reaches zero. A missing session is a no-op. Both changes are transactional.
Do not add an exercise reducer or seed data automatically. All operations must work for arbitrary inputs, not just one example. Failed operations must leave every table unchanged.
