Write a SpacetimeDB backend module in C# that reads deployment settings from database environment variables. Do not hard-code their values, and do not store them in a configuration table.

Declare these environment variables:
- REGION: required, any string.
- MODE: required, and only "development" or "production" are allowed.
- BANNER: optional, any string.

The deployment supplies the values when the module is published.

Public table DeploymentNote (fields in this order): Id (uint primary key), Region (string), Mode (string), Banner (string).

Reducers:
- RecordDeployment(uint id): insert a row holding the current REGION, MODE and BANNER. Use "(none)" for Banner when BANNER is absent. Reject an existing id with "note exists". Never overwrite a row.
- RequireDevelopment(): fail with "production locked" when MODE is production. Otherwise succeed.

Public anonymous view CurrentDeployment: returns a List holding exactly one row with Region (string) and Mode (string), in that order, read from the environment variables.
