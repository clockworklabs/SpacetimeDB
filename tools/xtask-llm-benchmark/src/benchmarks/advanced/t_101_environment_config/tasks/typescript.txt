Write a SpacetimeDB backend module in TypeScript that reads deployment settings from database environment variables. Do not hard-code their values, and do not store them in a configuration table.

Declare these environment variables:
- REGION: required, any string.
- MODE: required, and only "development" or "production" are allowed.
- BANNER: optional, any string.

Public table deployment_note (fields in this order): id (u32 primary key), region (string), mode (string), banner (string).

Reducers:
- record_deployment(id: u32): insert a row holding the current REGION, MODE and BANNER. Use "(none)" for banner when BANNER is absent. Reject an existing id with "note exists".
- require_development(): fail with "production locked" when MODE is production. Otherwise succeed.

Public anonymous view current_deployment: returns an array holding exactly one row with region (string) and mode (string), in that order.
