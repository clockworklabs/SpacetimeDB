Write a SpacetimeDB backend module in C# that throttles searches per caller.

Tables (fields in this order; the first field is the primary key):
- public SearchLog: Id: ulong (auto-increment), Owner: Identity, RequestId: string, Term: string, with one btree index on (Owner, RequestId)
- private SearchBucket: Owner: Identity, Tokens: uint, RefilledAt: Timestamp

Expose reducer LogSearch(requestId: string, term: string). Fail an empty term with "empty term".

Each caller starts with three tokens. Each new accepted request consumes one token. Refill one token per complete five seconds of server time, up to three tokens. Keep partial refill intervals, and start refill timing when the caller's bucket is first created. Calls must stay correct under concurrency.

An exact replay of a requestId by the same caller succeeds without inserting a row or spending a token. Reusing that caller's requestId with another term fails with "request conflict". Different callers may reuse the same requestId. Fail a new request with no token left with "rate limited"; a failed request must not insert a row or consume a token.
