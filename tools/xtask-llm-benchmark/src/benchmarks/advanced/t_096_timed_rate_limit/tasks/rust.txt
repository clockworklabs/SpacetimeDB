Write a SpacetimeDB backend module in Rust that throttles searches per caller.

Tables (fields in this order; the first field is the primary key):
- public search_log: id: u64 (auto-increment), owner: Identity, request_id: String, term: String, with one btree index on (owner, request_id)
- private search_bucket: owner: Identity, tokens: u32, refilled_at: Timestamp

Expose reducer log_search(request_id: String, term: String). Fail an empty term with "empty term".

Each caller starts with three tokens. Each new accepted request consumes one token. Refill one token per complete five seconds of server time, up to three tokens. Keep partial refill intervals, and start refill timing when the caller's bucket is first created. Calls must stay correct under concurrency.

An exact replay of a request_id by the same caller succeeds without inserting a row or spending a token. Reusing that caller's request_id with another term fails with "request conflict". Different callers may reuse the same request_id. Fail a new request with no token left with "rate limited"; a failed request must not insert a row or consume a token.
