Write a SpacetimeDB backend module in TypeScript that stores private notes and shows each user their notes for a given tag.

Tables (fields in this order; the first field is the primary key):
- private private_note: id: u64 (bigint), owner: Identity (btree index), tag: string, text: string

Reducers:
- put_note(id: u64 (bigint), tag: string, text: string): The caller owns a new note. Only its owner may replace it; otherwise fail with "owner only".
- remove_note(id: u64 (bigint)): Only the note's owner may remove it; otherwise fail with "owner only". Removing a missing note succeeds and changes nothing.

Expose a public, per-user view notes_for_tag(tag: string). It takes the tag as an argument and returns only the caller's notes with that exact tag, as id and text in that order. The view has no primary key. Users may subscribe to several tags at once. Moving a note to another tag, editing it or deleting it must update the matching subscriptions. Other users must not see the caller's notes or read the private table.
