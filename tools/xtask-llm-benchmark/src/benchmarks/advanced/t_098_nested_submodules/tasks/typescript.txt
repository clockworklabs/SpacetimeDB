Write a SpacetimeDB backend module in TypeScript that moves stock between mounted inventory modules. Write only the root source. The project already contains two fixed modules in the same folder, which you must not edit:
- ./inventory: public table item (id: u64 (bigint) primary key, quantity: u32). It exports the table as item, the reducer set(ctx, { id, quantity }), and the helpers take(ctx, id, quantity) and add(ctx, id, quantity). take rejects a missing item or insufficient stock. add uses checked arithmetic.
- ./branch: mounts that same ./inventory module as stock.

Mount ./branch twice as east and west. Mount ./inventory directly as reserve. These must be independent instances, not aliases.

Reducers:
- set_stock(location: string, id: u64 (bigint), quantity: u32): call set from ./inventory on the selected instance.
- transfer(source: string, destination: string, id: u64 (bigint), quantity: u32): move stock using take and add from ./inventory with the selected contexts, atomically. Accept only "east", "west" and "reserve". Fail any other location with "invalid location", identical locations with "same location" and zero quantity with "invalid quantity". If either helper fails, leave both instances unchanged.

Expose public anonymous views east_stock and west_stock that return each branch's stock.item rows. Define no root tables.
