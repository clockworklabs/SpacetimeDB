Write a SpacetimeDB backend module in C# that moves stock between mounted inventory modules. Write only the root source. The project already references two fixed assemblies:
- Inventory: public Item table (Id: ulong primary key, Quantity: uint) and Inventory.Functions helpers Set(ctx, id, quantity), Take(ctx, id, quantity) and Add(ctx, id, quantity). Take rejects a missing item or insufficient stock. Add uses checked arithmetic.
- Branch: mounts that same Inventory assembly as Stock. Branch.Marker identifies the Branch assembly.

Mount Branch twice as East and West. Mount Inventory directly as Reserve. These must be independent instances, not aliases.

Reducers:
- SetStock(location: string, id: ulong, quantity: uint): call Inventory.Functions.Set on the selected instance.
- Transfer(source: string, destination: string, id: ulong, quantity: uint): move stock using Inventory.Functions.Take and Add with the selected contexts, atomically. Accept only "east", "west" and "reserve". Fail any other location with "invalid location", identical locations with "same location" and zero quantity with "invalid quantity". If either helper fails, leave both instances unchanged.

Expose public anonymous views EastStock and WestStock that return each branch's Stock.Item rows. Define no root tables.
