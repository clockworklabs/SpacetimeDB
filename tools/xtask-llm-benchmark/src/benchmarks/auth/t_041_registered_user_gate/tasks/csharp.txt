Write a SpacetimeDB backend module in C# that gates actions behind a registration check.

TABLES
- User
  - Struct: User
  - private table
  - Fields:
    - Identity: Identity (primary key)
    - Name: string

- Message
  - Struct: Message
  - public table
  - Fields:
    - Id: ulong (primary key, AutoInc)
    - Sender: Identity (index BTree)
    - Text: string

REDUCERS
- RegisterUser(ctx, string name)
  - If a User row already exists for the caller's identity, fail with "already registered"
  - Otherwise insert a new User with Identity = the caller's identity and the given Name

- PostMessage(ctx, string text)
  - If no User row exists for the caller's identity, fail with "not registered"
  - Otherwise insert a Message with Sender = the caller's identity and the given Text
