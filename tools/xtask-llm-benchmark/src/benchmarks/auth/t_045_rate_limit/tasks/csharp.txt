Write a SpacetimeDB backend module in C# that enforces per-identity rate limiting.

TABLES
- RateLimit
  - Struct: RateLimit
  - private table
  - Fields:
    - Identity: Identity (primary key)
    - LastCallUs: ulong  (microsecond timestamp of the last allowed call)

- ActionLog
  - Struct: ActionLog
  - public table
  - Fields:
    - Id: ulong (primary key, AutoInc)
    - Identity: Identity
    - Payload: string

REDUCERS
- LimitedAction(ctx, string payload)
  - Get the current time in microseconds
  - Look up the RateLimit row for the caller's identity
  - If a row exists and (now - LastCallUs) < 1_000_000, fail with "rate limited"
  - Insert or update the RateLimit row with LastCallUs = now
  - Insert an ActionLog row with Identity = the caller's identity and the given Payload
