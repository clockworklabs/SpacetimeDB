# Address book

Update the existing store so customers can keep more than one shipping address.
Bring each customer's saved recipient name and address into their address book
as its default entry. Keep the existing store and its customer data working.

Customers can add, edit and delete addresses and choose a default. The first
address becomes the default. To delete the default when other entries exist,
the customer must first choose a replacement. Deleting the last entry leaves
an empty address book.

Keep the existing profile view usable: it shows and edits the current default
address. Saving a profile when the address book is empty creates its first entry.
