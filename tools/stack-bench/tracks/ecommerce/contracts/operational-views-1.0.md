# Operational view testing interface

| Test id | Required element |
| --- | --- |
| `low-stock-list` | Contains items with 10 units or fewer. |
| `low-stock-item` | Shows one item in `low-stock-list`. |
| `category-row` | Shows one product category. |
| `category-units` | Shows units sold inside its `category-row`. |
| `category-revenue` | Shows revenue inside its `category-row`. |
| `recommended-list` | Contains recommendations. |
| `recommended-item` | Shows one item in `recommended-list`. |
