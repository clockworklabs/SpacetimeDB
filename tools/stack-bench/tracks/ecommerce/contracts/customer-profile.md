# Customer profile application interface

Make `profile-link` available from the catalog while signed in, without first opening another
area. Use it to open the profile. Use `profile-name` and `profile-address` for the editable
values. Use `profile-save` to save them. Show the saved address in `profile-address-summary` on the same
view whenever the profile has one: right after `profile-save`, and again whenever the profile
is opened later, in the same session or a new one.
