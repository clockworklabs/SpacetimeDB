## Staff access controls

Use the existing account sign-in controls. Use `staff-link` for the staff area and `admin-link`
for the administrator area. Navigation links may remain visible to other users.
Mark the authorized staff content with `staff-area`. Show this hook only when the signed-in
account can use that content; do not put it on an access-denied message.

Use these provided accounts:

- staff: `staff` / `stackbench-staff-2026`
- administrator: `admin` / `stackbench-admin-2026`
- customer: `customer` / `stackbench-customer-2026`
