# Recommendations application interface

Use `recommended-list` for recommendations and `recommended-item` for each item in the list.
While a customer is signed in, `recommended-list` contains only that customer's recommendations. Use
`buy-now` inside an `item-card` to create customer purchase activity.
Use `catalog-link` to open the catalog with this list visible. Keep the list current when the
customer buys an item or adds an item to the cart.
