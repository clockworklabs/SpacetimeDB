What Stack Bench does

One system controls the full run.

The run plan, agent work, app services, tests, repairs, scoring, and evidence stay together.

01

Plan

Freeze the model, stack, features, tests, and limits.

02

Build

Give the agent an isolated workspace and exact stack access.

03

Test

Run product checks against the working application.

04

Repair

Return failed checks to the agent within a set limit.

05

Score

Measure each feature path, then compare complete runs.

06

Record

Keep the prompt, source, results, cost, time, and visuals.

Build and repair

Every open feature gets a fair attempt.

Stack Bench builds the current work, tests it, and returns useful failures. A repair attempt counts only after a valid test finds an app defect.

Run record

Every result keeps its full context.

You can see what ran, how the app changed, why checks passed or failed, and what the run cost.

Resume is exact. Additional repair attempts continue from the recorded source and state. They do not rewrite the earlier run.
